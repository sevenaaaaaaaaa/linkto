# LinkTo Mobile 更新日志

移动版与桌面版独立编号；移动版标签使用 `mobile-v` 前缀。

## 0.7.1 — 2026-11-11 · 邮件行动工作台首个预发布

### 在手机上直接处理

- 独立 Agent 底部入口：邮件提取待办并排程、重点摘要、整理今日、批量归档已读邮件。邮件多选后可以直接交给 Agent。
- 短左滑显示操作按钮，完整左滑快删待办或将邮件移至垃圾箱；右滑完成待办、置顶便签或归档邮件。保留按钮入口和可用的撤销。
- 待办和随手记点击展开即可修改；切页后恢复本次解锁期间未保存的输入，保存时检查版本，避免覆盖另一设备的新内容。
- 长按多选，批量完成、改期、删除、归档或移动；部分失败会报告已完成数量，不自动重试服务器写操作。
- 邮箱文件夹支持新建、改名、删除空文件夹及同邮箱移动；移动时可直接新建目标文件夹并移入，重试跳过已完成部分。系统及同步文件夹受保护。
- 待办和随手记支持文件夹分组、改名、移除分组；分组随内容加密同步，新建内容继承当前分组。

### 邮件、今日与随手记

- 全局新建邮件或随手记；随手记填入日期时间后成为待办，并可保留原邮件入口。
- 今日安排支持优先级、时长、固定时间、拖动重排、休息与间隔设置、自动填入空档及本机提醒；月历点选与时间步进用于改期。
- 使用自己的 IMAP 邮箱承载待办及随手记加密同步，兼容更新后的桌面同步协议。本机缓存同样加密。
- 统一收件箱、前台收信、搜索、阅读与纯文本发信；支持归档、稍后处理及附件预览 / 分享。
- 微软个人与组织邮箱统一入口并使用设备代码授权；其他邮箱按服务商要求配置应用密码或授权码。

### 安装与当前范围

- **iPhone / iPad**：0.7.1 / build 8，arm64，iOS 15.1 及以上。IPA 已内置 JS，但**未签名且未包含描述文件**，须用自己的证书和有效描述文件签名后安装；不是 TestFlight 包。
- **Android**：Preview APK 使用 `com.linktomobile.preview` 与固定预览签名，可覆盖同签名的 Preview；与正式应用分开存储。尚未在真实 Android 设备验收。
- Agent 的 AI 工作流需要在这台手机配置接口及 Key，会把选中邮件内容发送至该接口；配置不足时在读取正文前停止。默认最多分析 8 封、归档 20 封，范围为当前加载或手选邮件。
- 前台轮询尚不等于后台新邮件推送；系统日历双向同步、富文本发信与离线发件队列仍未接入。Proton Bridge 只在电脑运行，手机暂不支持直连 Proton。
- 未保存输入在锁定 / 退出应用时清理。分组导航目前在移动端提供，桌面保留分组元数据。

### 验证

- 19 个测试套件、82 项检查及移动端类型检查通过。
- iPhone 模拟器原生流程验证了拖动排程、切页恢复输入、短滑 / 完整左滑、批量操作与撤销、月历、分组及 Agent 本机工作流。
- IPA 完整性与真机架构、Android Preview 签名检查通过。真实邮箱 / AI 服务联调及真实 iPhone 安装尚未验收。
