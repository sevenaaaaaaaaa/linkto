## 2. Phase B 信息架构收敛建议（据问题清单）

1. **侧栏三分区**（示意见风格板 05）：
   - 核心：收件箱（统一）· 旗标 · 已发送 / 草稿（跨账户聚合）
   - 队列（可折叠，组标题显示合计数）：稍后处理 · 待审批 · 待跟进 · 置顶
   - 智能：洞察 · 知识库 · Agent
   - 账户（默认折叠为一行一个账户，展开才显示文件夹）
   - 「个人 / 通知 / Newsletter / 噪声」**退出侧栏**，只作为列表内的分段控件
2. **列表头合并为一行**（44px）：标题 + 计数 · 分段控件「重要 / 其他 / 未读」· 排序 / 聚合 / 存视图 / 时光机 / 重力 → 收进「⋯」与 ⌘K。搜索移到侧栏顶部或 ⌘F 唤起的浮层。
3. **BulkBar → 浮动液态玻璃条**（不占列表高度）：高频 4 个「归档 · 已读 · 稍后 · 移动」+ ⋯；Screener 视图下替换为「放行 · 拒绝」，Snooze 视图下替换为「取回」。
4. **Reader 动作分组**：主按钮「回复」实心 + 「全部回复 / 转发」 | 「归档 · 稍后」 | ⋯（置顶、旗标、删除、存知识库、分享、网盘、风格、标未读）；< 1280px 时仅图标 + tooltip。AI 助手由常驻卡改为 ⌘J 唤起 / 摘要自动折叠为一行。
5. 选中与勾选分离：打开 = `--selected` 底；勾选框只在 hover 或进入多选后出现。
6. 多选时 Reader 显示「已选 N 封」汇总 + AI 批量动作（提问 / 魔法排序 迁到这里）。

## 3. 目标风格板（六项交付物）

完整数值见 `design/tokens-v2.css`，下表为摘要。**需要 owner 拍板的只有 3.1 的 accent 选择**，其余可直接进入 Phase C。

### 3.1 色板

| token | 浅色 | 深色 | 说明 |
|---|---|---|---|
| `--bg` | `oklch(97.6% .004 95)` | `oklch(17.5% .006 260)` | 「石墨纸」：去掉奶油黄，保留一丝暖 |
| `--surface-strong` | `oklch(99.4% .002 95)` | `oklch(21.5% .007 260)` | 内容面实底 |
| `--fg / --muted / --faint` | 21 / 43 / 53.5% L | 94 / 73 / 62% L | 三级拉开：16.5 / 7.6 / 4.8 : 1 |
| `--accent` | `oklch(52% .105 192)` 铜绿 | `oklch(78% .11 188)` | **唯一品牌色**；渐变第二色退役 |
| `--accent-ink`（新） | `oklch(45% .1 192)` | `oklch(85% .1 188)` | soft 底上的文字，≥5.5:1 |
| `--selected`（新） | accent 10% | accent 13% | 选中行 |
| 语义 | ok 148° · warn 65° · danger 22° · info 255° | 同色相提亮 | 每个都拆 fill / ink / soft 三档 |

**为什么是铜绿**：Things 蓝、Linear 靛、Raycast 红、Spark 蓝已占据邮件 / 效率工具的常见色；铜绿（器物包浆色）在品类里辨识度高，饱和度低于纯青，符合「克制」；与 ok 绿（148°）色相差 44°，且 ok 只出现在小面积状态点上。
**备选（若 owner 更想要暖调）**：朱砂 `oklch(58% .17 35)` —— 代价是必须把 danger 推到 `oklch(50% .2 15)` 并给所有破坏性操作加图标区分。

### 3.2 字号表（17 → 7 级）

| token | px / 行高 | 用途 | 合并的旧值 |
|---|---|---|---|
| `--text-2xs` | 11 / 14 | 计数、kbd、mono 分组标题 | 9.5 · 10 · 10.5 · 11 |
| `--text-xs` | 12 / 16 | 元信息、时间、chip | 11.5 · 12 · 12.5 |
| `--text-sm` | 13 / 18 | **UI 默认**：侧栏、列表、菜单 | 13 · 13.5 |
| `--text-base` | 14 / 22 | 阅读正文、输入框 | 14 · 14.5 |
| `--text-md` | 16 / 22 | 区块 / 对话框标题 | 15 · 16 |
| `--text-lg` | 20 / 26 | 阅读窗主题、视图标题 | 18 · 19 · 22 |
| `--text-xl` | 26 / 32 | 空状态 / 洞察大字 | 26 |

字重只用 400 / 500 / 600；body 字体改为系统优先（PingFang 先于 Space Grotesk），Space Grotesk 仅作 display 与数字。

### 3.3 间距表

4px 基线 10 档：2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32 · 48。组件节拍：标题栏 52 = 列表头 = Reader 工具栏（三栏顶边对齐）、工具条 44、侧栏行 28、列表行 72（舒适）/ 44（紧凑，接 `GeneralSettings.density`）、控件 24 / 28 / 32、栏宽 232 / 360 / ≥480（1100px 窗口下三栏可完整容纳）。

### 3.4 圆角与描边

4 / 6 / 10 / 14 / full 五档（取代 26 / 18 / 12）；嵌套圆角 = 外 − 内边距；描边 1px，Retina 分隔线 0.5px；焦点环改双环 `0 0 0 2px var(--bg), 0 0 0 4px var(--accent)`，不再覆盖元素圆角。**组件一律用 `rounded-[var(--r-*)]` 或 `@theme` 映射类，禁止字面圆角**，这样预设的「形」才能真正生效（M-3）。

### 3.5 材质使用规则

| 层 | 材质 | 允许的位置 |
|---|---|---|
| L0 基底 | `--bg` 实色 + 1 团淡 accent 环境光 | body |
| L1 框架 | `.glass`（regular） | 仅侧栏 / 标题栏 |
| C 内容 | `--surface-strong` 实底 | 列表、阅读区、正文卡、设置内容（**去掉正文卡 blur**） |
| L2 浮层 | `.liquid-glass`（morph 时 thick） | 菜单、popover、⌘K、toast、BulkBar |
| Clear | `.liquid-glass-clear` | 仅媒体之上 |

同屏最多 2 种玻璃；浮层内不再嵌玻璃；阴影只留 `--shadow-sm / --shadow` 两档且只配 L2，阴影色改为中性 hue 260。

### 3.6 动效曲线

`--ease-out`（默认）· `--ease-spring`（进入 / morph）· 新增 `--ease-in`（退出）；时长 90 / 160 / 240 / 360ms 四档；退出 = 进入 × 0.7；位移 ≤ 8px、缩放 ≥ 0.96；取消 hover 上浮；`reduced-motion` 下 dur-3/4 归零、仅保留 dur-1 淡入淡出。

### 8.2 顺带修复的缺陷

- **IA-1** 侧栏双激活：激活态改为「视图（hash）+ scope」单一来源（`lib/route.ts`），且从知识库等视图点任一邮件入口都会回到邮件视图（原来部分入口不切 hash）
- **⌘F 失效**：原选择器 `input[placeholder="搜索邮件"]` 与实际占位符不一致，改为 `data-mail-search`
- **旗标会关闭阅读窗**：`act('flag')` 原本也执行 `select(null)`
- **「标为未读」逻辑颠倒**：原来只在未读时显示；现进 ⋯ 菜单并按状态切换文案，图标由刷新改为信封
- **Reader 稍后按钮丢失**：状态与 SnoozeMenu 已存在但未渲染，现恢复
- **浮层定位失效**：`.liquid-glass { position: relative }` 是无层样式，压过 Tailwind `fixed / absolute` → 发件队列浮条、全局 toast 实际都没有固定定位。材质类已移入 `@layer components`
- 术语统一：旗标（原「已加旗标 / 星标 / 旗标」）、订阅（原「Newsletter / 订阅」）
