# LinkTo（林可兔）

**会做事的 AI 邮件工作台** —— OpenFlow 家族「林」字辈成员。

> 命名：Link 音译「林可」，to 音译「兔」——动若脱兔，取其快；「林」呼应家族品牌「林下」命名安排。品牌标「年轮 @」：@ 是邮件，两圈年轮是越用越厚的 Agent 记忆，荧光内核是 AI，向右的尾线是 To。

一个人每天从邮件里收到各种信息：工作往来、账单订阅、订单物流、会议、通知、资讯、合同发票……LinkTo 不只是收发邮件：

1. **先是一个好用的多账户邮件客户端**——面向重度用户，海量邮件里快速拿到有效信息，交互克制、不复杂。
2. **再把邮件里的事整理成能行动的东西**——待办、款项、项目、到期事务、留痕、知识，并且和 IM、日历、网盘、笔记工具打通。
3. **最后由 Agent 替你跑腿**——查证、汇总、起草、提醒，改动和发信都先问你。

邮件比聊天工具更有条理，适合作为接收正式信息的入口，也适合为口头约定这类「轻量但需要留痕」的事情留下记录。

## 邮件

- **多账户一屏管**：左侧账户栏像切换工作区一样切换邮箱（⌘0–⌘9），每个账户一种颜色，贯穿列表、阅读页与文件夹；未读与同步状态挂在账户上。
- **一键添加账户**：Gmail（浏览器授权）、Outlook / Hotmail / Microsoft 365（设备码授权）；QQ / 163 / 126 / 139 / 新浪 / 腾讯企业邮 / 阿里云邮 / iCloud / Yahoo / Zoho 等预设齐全，授权码获取步骤逐一列出；输入邮箱地址自动识别服务商。Proton Mail 通过 Proton Mail Bridge 接入。
- **AI 分区收件箱**：每封新邮件做一次「邮件理解」（AI 或本地规则），给出一句话要点、关键短语、时间 / 金额 / 验证码等实体和建议的下一步；订阅与通知自动打包，不打扰你。
- **读信即行动**：要点卡、实体卡（一键提醒 / 复制）、AI 建议的下一步、快速回复草稿；阅读页会显示这封邮件关联的待办、款项、项目、跟进和留痕。
- **逐封处理**：一次一封，归档 E · 稍后 S · 回复 R（AI 已起草）· 跳过 ↓。
- **出错有下一步**：AI、账户、网络出错都给出中文说明和对应按钮（重新登录 / 重试 / 去设置）；离线时已缓存的邮件照常可读，操作在联网后同步。

### 搜索

- 关键词优先、边输边搜；中文单字、双字都能搜到，十万封邮件的常见查询在 0.2 秒内完成，结果按相关度和时间排序。
- 本地搜索语法（不依赖 AI）：`from:` `to:` `subject:` `has:attachment` `is:unread` `is:flagged` `before:` `after:` `in:`，以及中文别名（如 `有附件`、`未读`、`近30天`）。
- 像问句一样输入（「帮我找上周李若发的设计稿」）时，先给出关键词结果，再由 AI 理解后补充；AI 不可用时保留关键词结果。

### 撰写

- 收件人以地址胶囊显示，联想按「我发给过谁 › 往来频次 › 最近」排序，支持拼音与首字母（`wangxm` → 王小明）。
- 撰写窗内的 AI：用要点写整封邮件，对选中的文字润色、改正式、改简洁、翻译；AI 起主题。
- 发送前检查：提到附件但没附上、主题为空、地址无效、回复全部时包含了自己。
- 自动保存草稿、拖入附件、切换发件账户时自动换成对应签名；可延迟发送或定时发送（发出前可撤销）。
- **发出后跟进**：选择「N 天没回提醒我」，对方回信后自动结束；到期未回会提醒你，并起草一封更明确的催促（只起草，不会自动发送）。

## Agent

侧栏「Agent」下有对话 · 技能 · 自动任务 · 记忆四个子页，常用技能可以钉在侧栏一键运行；右侧上下文栏（⌘J）共享同一组对话，并自动带上当前这封邮件。

- **工具调用式运行时**：Agent 会把问题拆成多步，先查证再回答，每一步做了什么（比如「搜索邮件 → 找到 12 封」）都会显示出来；回答里的来源可以点开，跳到对应的邮件、待办、款项、项目或附件。
- **权限分级**：
  - 只读查询自动执行。
  - 改动数据（归档、建待办、标记已付等）先弹确认卡、写明理由，可以选择「本次对话都允许」。
  - 对外动作（发信、上传网盘、发到 IM）每次都要确认。
- **兼容性**：模型不支持函数调用时，自动改用 JSON 动作协议，内置本地模型也能用。
- **技能库**：40 多个内置技能，覆盖每日、收件箱、人脉、项目、财务、资料、出行、写作、生活事务等类别，例如：
  - 晨间简报、谁在等我回复、我在等谁（附催促草稿）、批量清理建议
  - 会前准备、承诺盘点、项目周报、订阅体检、对账差异跟进、报销材料整理
  - 行程汇总、快递追踪、按我的语气回复、把聊天整理成书面确认
  - 也可以复制内置技能修改，或从头写自己的技能：写任务说明、加参数、勾选允许用的工具、预先授权某些改动，并设定按小时 / 天 / 周运行。
- **事件触发**：新邮件识别为发票、行程变更、异常登录、合同、会议纪要、快递异常、续期提醒等事件时，自动运行对应的技能（只对新到的邮件；有次数上限）。
- **自动任务**：待办每小时补扫；财务、附件、项目、生活档案每天整理；知识库在后台自主学习；规则建议、跟进检查、订阅更新、会后跟进、每周自动备份等。每项都能开关、立即运行、查看结果；后台 AI 用量可设每日上限，也可设为只在接通电源时运行。
- **活动记录**：按天列出「今天 Agent 替你做了什么」，每条都能点开。
- **长期记忆**：从邮件里沉淀事实、偏好、人物关系、承诺、惯例，用于起草、问答和简报；发件人画像总结你们的关系与常聊话题；所有记忆都可以查看、编辑、归档。

## 整理中枢

| 入口 | 说明 |
| --- | --- |
| **待办** | 从邮件和会议自动收集；带项目、标签、情境、精力、清单、重复等维度；列表 / 看板 / 周视图 / 四象限；自动排程，会避开日历上的忙碌时段；会议前提醒、一键入会，会前准备和会后跟进交给 Agent。 |
| **财务** | 账单、订阅、电商订单、发票、付款、回单自动识别并归并（一笔钱对应多封邮件）；订阅推断周期、提价、试用期与可能闲置；企业对账（发票 ↔ 付款 ↔ 回单配对，标出缺失和金额不符）；读取 PDF 发票核对金额；概览 / 日历 / 导出 CSV。 |
| **项目** | 一件事的多封邮件归在一起：自动归入（拿不准的进入「建议归入」）、AI 发现项目、时间线（邮件 / 附件 / 待办 / 款项 / 里程碑）、进展摘要；同样的时间线也能用来看与某个联系人或公司的全部往来。 |
| **生活档案** | 证件、保险、车辆年检、会员、域名、保修、租房、税务、体检等到期事务；按类别提前提醒（护照提前半年）；时间线 / 月历 / 按类别查看；可生成待办或导出 .ics；证件号只保留尾号。 |
| **留痕** | 把电话、微信、会议里说定的事记下来：粘贴聊天记录或拖入截图，AI 整理出结论、约定和待确认事项（原文里没有的金额、日期不会被写入）；一键起草书面确认并挂上跟进，对方回信后标记「已确认」或「有异议」；保留历史版本与内容校验（⌥⇧⌘L 随时记一笔）。 |
| **等待对方** | 已登记的跟进（状态、等了几天、催了几次），以及「已发出未回复」的邮件。 |
| **知识库** | 一键收藏邮件；后台从高价值邮件和 PDF 资料里自动沉淀条目并去重；支持基于知识库的问答。 |
| **附件** | 附件中心（按类别 / 对方 / 时间 / 账户浏览）；本地占用统计和重复文件检测；一键按「分类 / 年份 / 对方」归档到 Proton Drive、Dropbox 或 WebDAV；安全地释放本地空间（只删能找回的文件，再次打开时自动重新下载）。 |

**附件内容**：可以读取 PDF、Word / Excel / PowerPoint（含旧版 .doc / .xls / .ppt）、文本 / HTML / eml 的内容；扫描件和图片可以识字：
- 本机识字：macOS 用系统文字识别，Windows 用系统 OCR，Linux 用 tesseract。
- AI 识字：交给视觉模型，能还原表格。
- 本机识字 + AI 校对。

**规则**：可视化规则与一键配方；LinkTo 会观察你反复做的手动操作（比如某类通知总是不读就归档），在门槛足够高时主动建议建一条规则，你确认后才生效。

## 信息入口与打通

### 订阅

- RSS / Atom / JSON Feed（含 GBK 编码的源）：粘贴网址自动发现订阅地址，支持 OPML 导入导出，可按订阅源开启全文抓取。
- **AI 搜索订阅**：比如「每天关于某个行业的新闻」，默认使用免费的新闻搜索，也可以填写 Brave / Tavily / SerpAPI 的 Key；新结果去重后由 AI 写成简报，简报里的链接只来自搜索结果。
- 阅读方式和邮件一致（J/K、已读、收藏），每条可以 AI 摘要、存知识库、加入阅读清单、转待办、分享；「今日订阅精华」可以并入今日简报。
- 抓取时会拦截内网和本机地址。

### 分享与导出（⌘⇧E）

- **导出**：EML、PDF（多封可合并）、Markdown（附件放在同名文件夹）、长图；也可以复制为富文本或链接。`linkto://` 链接在本机点开会定位到对应邮件，另附网页版邮箱的备用链接。
- **工作 IM**：企业微信、钉钉（支持加签）、飞书 / Lark（支持签名）、Slack、Microsoft Teams，都走群机器人 Webhook。
- **IM**：
  - Telegram：用机器人发送，可以直接发文件。
  - Discord：用 Webhook 发送。
  - 微信、WhatsApp：通过系统分享、剪贴板或深链接转过去。
  - 「信息」和隔空投送：走 macOS 系统分享菜单。
- **笔记与存储**：Apple 备忘录、Notion、flomo、任意 Markdown 笔记文件夹、本地文件夹、网盘。
- 对外发送前先预览，并由你确认；订阅文章也可以用同一个面板分享。

### 外部待办与日历

待办可以和 Apple 提醒事项、macOS 日历、Microsoft To Do / Outlook 日历双向同步（可选双向 / 只导出 / 只导入）；日历上的忙碌时段会参与待办排程。

### MCP

内置本地 MCP 服务（默认关闭，带访问令牌），可以把 LinkTo 的能力交给 Claude Code 等外部 Agent：搜索 / 阅读邮件、待办、知识库、财务、项目、附件等查询，以及新建本地待办、保存本地草稿；绝不代发邮件。

### OpenFlow 家族连接器

家族产品（OpenFlow 工作台 / inFlow / LearnFlow / MFlow / PayFlow）已按统一的 Intake 协议接入：产品侧只需暴露一个 Intake HTTP 入口，在 设置 → 集成 里填入 endpoint 和 API Key 即可。新增连接器的方法：在 `src/main/connectors/builtin.ts` 注册一个 `BuiltinConnector`（Manifest + 执行器）。

## 同步与备份

- **跨设备同步**（设置 → 同步与备份）：通过你自己邮箱里的隐藏文件夹同步，内容端到端加密，口令只有你知道。
  - **新设备怎么开始**：先登录任意一个邮箱，再输入同一个同步口令；其余账户会连同密码、应用专用密码、授权码、OAuth 令牌一起自动配置好，并立即测试连接。
  - **本机专用的账户**（例如 Proton Bridge）：只同步配置，会提示你在这台电脑上填写本机的密码。
  - **同步什么**：Agent 记忆、知识库、技能、待办、财务、项目、生活档案、留痕、跟进、订阅源、规则、模板、签名、个性化设置（包括侧栏布局）等，可以逐项开关。
  - **默认关闭的项目**：AI 的 API Key、分享 Webhook 的密钥（打开前会说明风险）、Agent 对话。
- **加密备份**：`.lkbak` 文件（AES-256-GCM + scrypt），可以按类别导出和恢复（合并，或以备份为准），兼容旧版备份。可以设定每周自动备份到 iCloud Drive、Dropbox、Proton Drive、坚果云、OneDrive 或任意目录，并保留最近几份。
- 口令一旦忘记，就无法解密，请妥善保管。

## 隐私与安全

- 邮件、记忆、知识库和各中心的数据都只存在本机（SQLite）；密码、令牌、API Key 用系统钥匙串级加密（Electron safeStorage）保存。
- **附件内容读取默认关闭**：你同意之后，LinkTo 才会读取附件的内容。「在本机读取」和「发给云端 AI」分开授权；可以按文件类型或账户排除。使用本地模型（Ollama / LM Studio / 内置引擎）时，内容不会离开本机。
- 邮件 HTML 在 Shadow DOM 里经过消毒后渲染（去掉脚本和事件属性），远程图片默认拦截，链接在系统浏览器中打开；渲染进程运行在沙箱里，启用了 contextIsolation 和 CSP。
- Agent 修改数据前需要你确认，发信和其他对外动作每次都要确认；AI 识别出的金额、日期、链接都会和原文核对，防止编造。
- 完整的威胁模型、萤火密信的信任边界、发布包 SHA-256 与阅读页哈希的校验方法见 [SECURITY.md](SECURITY.md)。
- 新版本会后台下载 DMG，并用 Release 的 SHA256SUMS.txt 校验；下载完提示重启，退出时也会自动安装（目前仅 macOS 安装版）。
- 萤火密信阅读窗可把内容暂存或存入保险箱；两者共用系统钥匙串加密存储。发送到 Litmus 会写成明文 Markdown，密码请用保险箱。
- 终端启动器：在仓库执行 `npm link`，然后 `linkto` 选择 LinkTo / Litmus / 开发版（`linkto list` 查看）。

## 快速开始

1. **添加邮箱**：设置 → 账户 → `+`，点服务商卡片。Gmail 需要在「OAuth 应用凭据」里填入你的 Google OAuth 客户端，Outlook 系需要填 Azure Client ID；没有配置时，会自动改为应用专用密码 / 授权码的引导流程。
2. **配置 AI**：设置 → AI 模型。可选：
   - **云端 API**：智谱 GLM、OpenAI、DeepSeek 等 OpenAI 兼容接口。
   - **本地部署**：Ollama / LM Studio，可以自动探测本机服务。
   - **内置引擎**：node-llama-cpp，下载模型后断网也能用，适合轻量任务。

   结构化功能建议用云端 API 或 7B 以上的本地模型。「自定义咒语」会追加到所有 AI 功能里。
3. **首次整理**：第一次打开（或升级后）会出现一个向导：
   1. 介绍新功能
   2. 附件内容读取授权
   3. 首次整理（扫描最近 30 / 90 / 180 天，整理出待办、财务、附件、知识库、项目和生活档案）
   4. 设置侧栏

   之后可以随时在 ⌘K 里重新打开。
4. **外部待办与日历**（可选）：设置 → 待办与日历。连接 Microsoft To Do / Outlook 日历时，需要在 Azure 应用注册里添加 `Tasks.ReadWrite`、`Calendars.ReadWrite` 委托权限；连接 Apple 提醒事项和日历时，第一次需要在 系统设置 → 隐私与安全性 → 自动化 中允许。

## 开发

```bash
npm install
npm run dev          # 开发模式
npm run typecheck    # 双 tsconfig 全量类型检查（改动后必跑）
npm run build        # 生产构建
```

验证闭环：typecheck → build → 用隔离的 `--user-data-dir` 启动 → CDP 截图核验（明暗两态）。

```bash
npx electron . --user-data-dir=/tmp/linkto-dev --remote-debugging-port=9224
node scripts/cdp-shot-only.mjs /tmp/shot.png   # CDP 截图
node scripts/smoke.mjs                          # IPC 全链路冒烟测试
```

约定：`src/shared/ipc.ts` 只增不改；AI 提示词集中在 `src/main/ai/prompts.ts`（只追加）；UI 颜色一律走 `src/renderer/src/styles/global.css` 的 token 层，同时适配明暗两态与主题预设。

## 发版

- **Nightly**：`scripts/daily-release.sh`。要求在 `main` 分支、工作区干净，然后执行：typecheck → 构建三平台安装包 → 刷新唯一的 `nightly` 预发布 → 替换本机 `/Applications/LinkTo.app`。可用 `--dry-run` 只在本地构建，或用 `--no-install` 跳过替换本机应用。
- **正式版**：先在 `CHANGELOG.md` 写好 `## X.Y.0 — 日期 · 主题`，再运行 `scripts/release.sh X.Y.0`（可加 `--dry-run` 预览发布说明）。
- **本机签名（macOS）**：运行一次 `scripts/setup-signing.sh`，会在登录钥匙串里创建自签名身份「LinkTo Local Signing」。之后的构建都用它签名，钥匙串授权在不同版本之间会保留（`--check` 查看状态，`--remove` 撤销）。没有这个身份时退回 ad-hoc 签名。
